# منوی آنلاین کافچی

سایت منوی آنلاین با امکان ثبت سفارش (حضوری / بیرون‌بر)، ساخته‌شده با Next.js (App Router) و کاملاً فارسی و راست‌به‌چپ.

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس http://localhost:3000 را باز کن.

برای نسخه‌ی نهایی:

```bash
npm run build
npm start
```

## امکانات

- منوی دسته‌بندی‌شده (نوشیدنی گرم، نوشیدنی سرد، چای و دمنوش، شیرینی و کیک) + جست‌وجو
- سبد خرید با ذخیره‌سازی در `localStorage` (با رفرش پاک نمی‌شود)
- محاسبه‌ی مالیات ۹٪ و مبلغ نهایی
- فرم سفارش با اعتبارسنجی نام و شماره موبایل و انتخاب میز / بیرون‌بر
- ثبت سفارش در `POST /api/orders` و ذخیره در `.data/orders.json` + شماره پیگیری
- طراحی ریسپانسیو با فونت وزیرمتن (لوکال، بدون نیاز به اینترنت)

## شخصی‌سازی

| چه چیزی | کجا |
| --- | --- |
| اسم کافه، آدرس، ساعت کاری | `lib/menu.js` → `cafe` |
| اقلام منو و قیمت‌ها | `lib/menu.js` → `menuItems` |
| دسته‌بندی‌ها | `lib/menu.js` → `categories` |
| عکس محصولات | `public/images/<image>.jpg` (نام فایل با فیلد `image` یکی باشد) |
| رنگ‌ها و فونت‌ها | `tailwind.config.ts` (theme.extend) و `app/globals.css` |

> نکته: عکس‌های نمونه از Unsplash گرفته شده‌اند و فقط برای پیش‌نمایش هستند. برای استفاده‌ی تجاری عکس‌های واقعی کافه را جایگزین کن.

## استایل و طراحی

- Tailwind CSS 3.4؛ رنگ‌ها، فونت‌ها، سایه‌ها و انیمیشن‌ها در `tailwind.config.ts` تعریف شده‌اند.
- فونت متن: وزیرمتن (لوکال با `next/font/local`) — فونت تیترها: Lalezar (`public/fonts`).
- آیکون‌ها: `lucide-react` با ضخامت یکسان.
- بافت نویز، انیمیشن ظاهر شدن هنگام اسکرول و استایل‌های پایه در `app/globals.css`.
- چیدمان RTL با logical properties (`ms-`/`me-`/`ps-`/`pe-`) نوشته شده است.

## سفارش‌های ثبت‌شده

هر سفارش در `POST /api/orders` اعتبارسنجی می‌شود و در فایل `.data/orders.json` ذخیره می‌شود.
برای دیدن سفارش‌ها همین فایل را باز کن. (این فایل در Git نادیده گرفته می‌شود.)

> برای انتشار روی هاست‌های بدون فایل‌سیستم دائمی (مثل Vercel) باید جای ذخیره‌سازی را به یک دیتابیس
> (مثلاً Postgres یا Supabase) یا ربات تلگرام تغییر بدهی؛ ساختار فعلی برای اجرای لوکال و سرور اختصاصی است.
